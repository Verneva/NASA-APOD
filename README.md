# NASA Astronomy Picture of the Day Viewer

This is a simple web app that lets you view NASA's Astronomy Picture of the Day (APOD) based on a date you select.

## Features
- Select a date (after June 16, 1995) to view the corresponding NASA image.
- Displays the image, its title, and explanation.
- Works with historical APOD entries.

## How to Use
1. Open `index.html` in your browser.
2. Enter a date in the date picker.
3. Click **Submit** to load the image and information.

## Technologies Used
- HTML
- CSS
- JavaScript
- NASA APOD API (https://api.nasa.gov/)

## Notes
- Some APOD entries are videos; currently, the app only displays images.
- For full functionality, you may want to register for your own free NASA API key.
